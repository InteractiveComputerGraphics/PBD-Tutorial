## Eurographics Tutorial 2017

A Survey on Position Based Dynamics, 2017

*Jan Bender, Matthias Müller, Miles Macklin*

This tutorial extends the 2015 tutorial with new content, e.g., on the variational formulation of the implicit Euler method with compliant constraints and on elastic rods.

* [A Survey on Position Based Dynamics, 2017](https://animation.rwth-aachen.de/media/papers/2017-EG-CourseNotes.pdf)

## Simulation Code

Many of the methods discussed in the course notes and the surveys are implemented in our open-source library PositionBasedDynamics. You can download the code here:

* [PositionBasedDynamics](https://github.com/InteractiveComputerGraphics/PositionBasedDynamics)

An introduction to state-of-the-art simulation methods in the area of visual computing (like PBD) is given here:

* [Physics Simulation in Visual Computing](https://interactivecomputergraphics.github.io/physics-simulation/)
